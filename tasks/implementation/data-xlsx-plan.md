Verify native default/private export and import exact restoration; external unsupported format behavior stays explicit. Confirm remote fetch still uses the checked downloader before the isolated file worker.
4. **Full path and gates.** Run focused core/data/formats/server tests, strict Clippy, formatting, frontend tests/typecheck/build and embedded server build. Use the production frontend in a 390px browser to upload the XLSX fixture, select its second sheet, run SQL, save/reload and inspect the exact typed result. Add an actual hosted remote-file fixture and run the relevant CI/database/platform gate for the commit before merging to `main`.

The slice completes XLSX only. Legacy XLS/XLSB/ODS, calculation of formulas, and arbitrary workbook links stay explicitly unsupported for later rows; do not mark all Spreadsheet formats complete from this batch.
