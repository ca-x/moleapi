# Workspace document request-link coverage

Scope: the private cross-resource request links specified in `docs/specs/document-resource-links.md`, extending `documentation-001` and the generated API reference preview. This does not publish documents or add cross-workspace access.

Canonical `[label](moleapi://request/<encoded-request-id>)` links decode exactly once and only render as active buttons when the current draft contains the target request. The click handler rechecks the current account, workspace and request before selecting the existing request editor. Missing, deleted, foreign, malformed or unsupported targets remain legible inert text; HTTP(S)/mailto external links retain explicit new-tab/noopener behavior, while script/data/file/relative links and remote images remain inert. The generated API reference can copy the selected request's canonical URI with success/failure feedback; neither action changes the saved source or executes a request.

Local evidence: a clean branch baseline passed 386 frontend tests. New red/green tests cover eleven URI variants, one-decode identity, active/missing/malicious preview links, stale account/workspace clicks, exact navigation, clipboard success/failure and unchanged draft data. The full frontend suite passed 401 tests, TypeScript and production build passed, the 46-chunk static ESM cycle verifier passed, and embedded server/CLI builds passed.

At 390 px, an embedded hosted English browser created an owned workspace, copied the first request URI from the API reference, inserted and saved a Markdown document link, and clicked it after first selecting the POST request. The click opened the linked GET request in the existing editor without changing the browser URL. Missing and `javascript:` labels were inert; no remote image request occurred. After deleting the linked request, the saved document's label became inert immediately and remained inert after save/reload. Chinese controls displayed after a live language switch. Page width remained 390 px; focused axe reported zero violations and one incomplete theme-background contrast analysis.

Open: independent review, fixed-head CI/database/Docker/native package gates and installed smoke. Public documentation URLs, cross-workspace permissions, attachment links and automatic link rewriting after deletion remain separate capabilities. The wider 395-item product goal remains open.
