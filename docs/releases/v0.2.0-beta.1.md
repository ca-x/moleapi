# MoleAPI v0.2.0-beta.1

This is a usable preview release of the self-hosted API workbench. It includes the HTTP workbench, saved requests and environments, scripts and collection runs, Mock responses, import/export, local desktop client, server binaries and a Docker image. It also includes the documentation, Data, request-version and Mock capabilities already merged into `main` at the release commit.

## Install

- **Docker:** `ghcr.io/ca-x/moleapi:0.2.0-beta.1` for `linux/amd64` and `linux/arm64`. Mount a persistent data directory and set a first-user setup token. For a local installation:

  ```sh
  docker run -d --name moleapi -p 127.0.0.1:8787:8787 \
    -v moleapi-data:/data -e MOLEAPI_SETUP_TOKEN='<long-random-token>' \
    ghcr.io/ca-x/moleapi:0.2.0-beta.1
  ```

  Open `http://127.0.0.1:8787` and use that token to create the first account. See `docs/BUILD-AND-RELEASE.md` and `docs/API-CONTRACT.md` for other configuration.
- **Server:** download the archive for your OS and architecture from this release, verify it against `SHA256SUMS`, extract the whole archive including `runtime/`, and run `moleapi-server --help` for bind/database options.
- **Desktop:** the tag build produces Linux, macOS and Windows installers as GitHub Actions artifacts. Desktop packages are unsigned; macOS/Windows signing and notarization are not included in this preview.

## Scope and limits

MoleAPI runs without a third-party hosted service. This release is a preview, not a claim of complete Apifox/Postman parity. Several advanced protocol, collaboration, publishing, AI, administration and platform acceptance capabilities remain in progress. The separate `feat/workspace-collaboration` draft is not part of this release. EDAS integration has not been verified against a real sandbox.

Release evidence must match this exact tag: Application CI including SQLite/PostgreSQL/MySQL, native server and desktop build jobs, Docker smoke on both architectures, and a published multi-platform manifest. A green workflow on an earlier commit does not establish this tag's artifacts.
