# MoleAPI v0.2.1

## 简体中文

MoleAPI 的首个稳定版本，提供独立服务端、离线桌面客户端和 Docker 镜像。

- 共享工作区支持邀请、管理员/编辑者/只读角色，以及请求、集合、变量、文档、数据集和 OpenAPI 规范的协作编辑。
- 成员可以发送 HTTP 请求、运行集合与场景、查看执行报告，并使用 GraphQL、SSE、WebSocket、TCP、Socket.IO、gRPC、MQTT、SOAP、MCP、A2A 和 Dubbo 工作台中已实现的功能。
- 共享 Mock 支持示例、脚本、匹配规则、Schema、数据集绑定和临时路由调试。
- 桌面客户端连接自托管服务后可以直接进入共享工作区，远程共享数据与本机工作区独立保存。

Docker 镜像 `ghcr.io/ca-x/moleapi:0.2.1` 提供 `linux/amd64` 和 `linux/arm64`：

```sh
docker run -d --name moleapi -p 127.0.0.1:8787:8787 \
  -v moleapi-data:/data -e MOLEAPI_SETUP_TOKEN='<自行生成的长随机令牌>' \
  ghcr.io/ca-x/moleapi:0.2.1
```

访问 `http://127.0.0.1:8787` 创建首个账户。服务端归档和桌面安装包按平台下载，使用 `SHA256SUMS` 校验；服务端归档需连同 `runtime/` 完整解压。升级前备份数据库和用户文件。

桌面安装包未签名或公证；EDAS 尚未经过真实沙箱验证，部分高级功能和原生界面验收仍在进行。共享工作区需要在线连接。完整范围与限制见仓库覆盖记录。

## English

MoleAPI's first stable release includes standalone servers, an offline desktop client and a Docker image.

- Shared workspaces support invitations, admin/editor/viewer roles and collaborative editing of requests, collections, variables, documents, datasets and OpenAPI specifications.
- Members can send HTTP requests, run collections and scenarios, inspect reports and use the implemented GraphQL, SSE, WebSocket, TCP, Socket.IO, gRPC, MQTT, SOAP, MCP, A2A and Dubbo workbenches.
- Shared Mock supports examples, scripts, matching rules, schemas, dataset bindings and temporary route debugging.
- Desktop clients connected to a self-hosted server can open shared workspaces while keeping remote shared data separate from local workspaces.

Docker: `ghcr.io/ca-x/moleapi:0.2.1` supports `linux/amd64` and `linux/arm64`; use the command above with your own first-user setup token. Download the server archive or desktop installer for your platform and verify `SHA256SUMS`. Extract server archives together with `runtime/`. Back up databases and user files before upgrading.

Desktop packages are unsigned and not notarized. EDAS has not been verified against a real sandbox; advanced capabilities and native GUI acceptance remain in progress. Shared workspaces require an online connection. Repository coverage documents describe the supported scope and limits.
