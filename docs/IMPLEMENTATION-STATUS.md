## Script extension review fixes

The current fix round replaces cooperative-only CPU enforcement with one worker process per phase, a distinct 1 second absolute startup/IPC watchdog and cancellation kill/reap. QuickJS retains its 250 ms cooperative interrupt, 64 MiB VM heap and 512 KiB VM stack caps. Regression checks cover native BigInt work, worker cancellation/output bounds, detached promises, prototype-named variables, negated property assertions, encoded local values after scope unset, and privacy from failed scripts. Failed script details remain live-only; incomplete privacy recovery forces phase failure even when JavaScript catches the quota error and withholds affected saved response data. History matching has explicit per-value/aggregate budgets, with conservative withholding above them. Local desktop compilation still lacks WebKitGTK4.1/JavaScriptCoreGTK4.1 system pkg-config packages; the changed entrypoint requires the root's platform build verification. Independent scoped re-review passed. Cross-platform release verification is pending for this extension; see `tasks/implementation/execution-report.md`.
