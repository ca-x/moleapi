## API Key, JWT and Digest authentication

The modular shared authentication provider adds API Key header/query placement, per-execution JWT signing through jsonwebtoken11.1 and Digest challenge handling through digest_auth0.3. Typed source retains inactive drafts and environment references. JWT supports twelve HMAC/RSA/PSS/EC/EdDSA algorithms with original JSON claims, optional key ID, placement/prefix and timestamp/expiry settings. Digest signs the actual method, target and retained byte body, including auth-int, and permits at most two challenge responses within the request deadline. Cross-origin redirects strip selected private headers/query parameters and disable Digest retries.

Default exports capture credential usage across global/collection/environment/native scopes, screen encoded/decoded HMAC and copied API/JWT values across requests, and retain multipart file reselection metadata when privacy budgets require withholding. Explicit include-secrets native backup preserves originals.
