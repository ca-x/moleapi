# Shared Dubbo client implementation plan

> **For agentic workers:** Execute inline using executing-plans and verification-before-completion, with one independent final source review.

**Goal:** Shared editors/admins author/save classic Dubbo direct/ZooKeeper/Nacos settings, perform canonical saved or temporary finite calls, and preview/stage metadata method/DTO imports with explicit CAS Save.
**Architecture:** Reuse existing controlled Dubbo form and official checked Java worker. Add finite Dubbo member draft admission and credential/member/revision fences for saved/draft calls. Extract pure metadata workspace transformation and checked reader for owner/member reuse; member routes use canonical saved request/revision/scopes, return screened preview or an unsaved workspace candidate, and never commit. Controlled metadata pane accepts source operations with exact async scope guards; owned persistence semantics remain compatible.
**Tech Stack:** Existing Apache Dubbo3.3.6/JRE worker, mature ZooKeeper/Nacos SDK/readers, serde, React/Radix; no wire parser or dependency changes.
**Spec:** docs/specs/dubbo-client.md, docs/specs/dubbo-discovery.md and shared Dubbo subsection of docs/specs/workspace-collaboration.md.

## Constraints/interfaces

- Shared saved/draft Dubbo uses canonical owner scopes and no member environment/data/temporary/locals overrides. Draft remains bound to saved collection/request identity and expected revision. Both retain credential/member/revision watching and final release fencing; dropping execution reaps the real worker. HTTP auth/body/network options unsupported by classic transport remain rejected. EDAS remains unverified without user sandbox.
- Member /dubbo/metadata/preview and /import require saved canonical request_id/expected_revision, editor role and creator credentials. Import adds document_sha256 and explicit per-method skip/add/replace_request_id decisions. No whole request/dialect/locals override. Target collection is derived from canonical request. Read only metadata fields resolve from canonical owner scopes; no script/invocation side effects during preview.
- Metadata import refetches and checks exact SHA and decisions, then reuses pure existing transformation for typed DTO drafts, source specification and exact replacement identity. Member result is an unsaved candidate at the same revision; ordinary explicit shared CAS Save persists it. Native/owned endpoint retains direct persistence and existing callback behavior.
- Canonical private values (request/registry/metadata credentials, inherited auth, collection/environment variables) screen preview/error/raw source/unknown keys/scalars; private source is withheld rather than rewritten. Network/reader budgets remain existing mature implementation; role/revision/logout cancels actual read and withholds candidate.
- DubboWorkbench and MetadataPreviewPane get optional current-scope/adapter hooks without owned context. Current account/workspace/request/environment/revision/draft/form/epoch binds preview/import/decisions/callbacks and capability reads; blocked/dirty shared sources do not call owner endpoints. Runtime/draft responses never rewrite saved source.

## Review focus

- Retained form/metadata/capability/import callback after account/request/draft/saving/version change cannot send, stage, replace or report success in another scope.
- Import candidate preserves every authored request except exactly selected replacement; raw source and original auth references survive without resolving secret values into saved config.
- Current canonical owner metadata auth/namespace/group wins over member same-ID workspace/locals; numeric/unknown-key private source/error values remain withheld.
- Pending read/call cancellation drops actual network/Java work on role/revision/logout/Stop; final source/workspace response cannot pass a stale authorization fence.
- Owned metadata preview/import remains usable and persistent; shared adapter never calls owned paths or implicitly commits before explicit CAS Save.
