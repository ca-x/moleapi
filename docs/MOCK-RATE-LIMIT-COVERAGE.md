# Shared Mock request rate-limit coverage

Scope: the per-minute request ceiling in `mock-013`, specified in [mock-rate-limit.md](specs/mock-rate-limit.md). It extends saved examples and the existing direct/routed/public/native Mock paths. It does not implement the full Postman Simulator.

An example may configure `rate_limit_per_minute` from 0 (disabled) to 1,000. Admission uses a sliding 60-second window of database-sourced timestamps and a transactionally locked owner/workspace row shared by hosted instances. One bounded counter document per owner/workspace/request/example stores at most 1,000 admitted timestamps. A denied call returns immediate 429, fixed text, no authored headers/body and `Retry-After`; the private call log records `rate_limited`. It does not run fault sampling, schema generation, scripts or the saved response delay. Saving a workspace resets its counters in the same CAS transaction; deleting it cascades to counter documents. Native backups retain the setting, while Postman/OpenAPI/HAR exports reject it.

Local evidence: old-example defaults, valid/invalid bound and native/default/full export roundtrip passed. Direct and routed real calls admitted two configured 502 fault responses, then returned 429 before the 100 ms delay; a workspace save reset admission and deletion removed counter documents. Two independent SQLite hosted routers racing on the same owner/example admitted exactly one of two calls; a second owner with the same workspace/example IDs had independent quota. Hosted public share and native listener socket tests returned fixed 429 after one admitted call. Corrupt counter payload failed closed without returning saved body. Cancelling an admitted delayed call still consumed its quota. A deterministic window test covered exact 60-second expiry and rounded `Retry-After`; SQLite's database-time expression showed a real 40 ms delta across two reads 40 ms apart. The configured-database test passed locally on SQLite; PostgreSQL/MySQL require their CI services. The full core/formats/server Rust suite passed before the one-line SQLite millisecond precision fix; affected Mock and configured-database cases passed again afterward. Scoped strict Clippy, rustfmt and diff checks passed at the corrected source. Focused bilingual editor/log tests passed 18 cases, the full frontend suite passed 380, TypeScript, production frontend and embedded server builds passed. At 390px, the embedded browser saved limit 2 in English and reloaded it; two authenticated routed calls returned 201, the third returned 429 with fixed body and `Retry-After: 60`. Chinese controls and the `已限流` log appeared without document overflow. axe reported zero violations and zero incomplete checks.
