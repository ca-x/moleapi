# Agent CLI discovery and skill

Complete the coding-agent integration capability with a standard self-contained MoleAPI SKILL.md and optional Codex interface metadata. Use the actual native/remote commands, IDs/unique names, environment/data/scenario/filter rules,23/55 generation catalog, report persistence/privacy/exit codes, personal token lifecycle and optional original Newman runtime. Preserve the user's chosen server/environment/authorization and credential boundaries; no fetched templates, new parser or alternative execution engine.

Embed the skill and UI metadata in the Rust CLI. `skill` prints Markdown; `skill --format json` returns a fixed file-content bundle for agent tooling; `skill --output PATH` exports through the existing atomic private/no-overwrite writer. Metadata/discovery commands run before native database/router or remote credential initialization and never create a database, start jobs or connect to services. They must be usable even when no credentials are configured. Export targets are explicit; do not automatically install into a user's agent directories.

Improve the Clap-derived schema with actual option conflicts and value cardinality, using its own introspection instead of a second grammar. Enforce run input/workspace selection and paired snippet workspace/request arguments through Clap so invalid commands cannot initialize storage. Validate the standard skill frontmatter/scaffold via the mature skill-creator tooling and use process fixtures for exported/embedded identity, fixed bundle entries, no-overwrite and side-effect-free discovery/invalid invocation. Existing actual execution/generation/report/credential fixtures are reused rather than repeated without changes. This is the CLI/agent entrypoint; broader AI/MCP/enterprise/release capabilities remain separate matrix requirements.
