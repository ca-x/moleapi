# AWS Signature V4

Authority: existing full authentication coverage requirement and feature matrix. Use the official aws-sigv4 SDK with aws-credential-types for canonicalization, SHA256/HMAC signing, headers, session-token placement and presigning. Do not implement AWS signing or canonical request parsing locally.

Modules: core typed AWS source/validation/SDK adapter; finite HTTP wire hook after body/query/header preparation; shared inherited/environment resolution and privacy; localized mature-component editor; native/Postman source formats and explicit unsupported generation mappings. No cloud login, metadata endpoint or ambient credential lookup. Supplied credentials stay account-owned source configuration.

Support access key, secret key, optional session token, service, region, signed/unsigned payload, header/query placement and bounded presign expiry. Default S3 path/checksum settings must come from the SDK. Sign actual encoded bytes after multipart/binary materialization. Re-sign same-origin redirects against the actual redirected method/body/path. Cross-origin redirects disable signing and never forward generated authorization/session/signature query fields. SDK-generated credentials/signatures join existing response/history privacy matching. No signature generation while saving/importing/exporting.

Preserve old JSON and inactive drafts. Workspace/folder inheritance and environment switching apply. Reject unsupported protocol execution (live transports, gRPC, SQL/native TCP/MQTT/MCP until actual wire-context adapters exist), invalid credentials/region/service, duplicate SDK-owned AWS query/header directives, streaming unknown body bytes and unsupported generator mappings explicitly.

Verification: independently pinned AWS published vectors, session-token header/query/presign expiry, Unicode/duplicate query and body exactness, altered payload signature differences, real HTTP fixture including same/cross-origin redirects, binary/multipart request bytes, default/full source roundtrip and copied/inherited secrets, UI environment/inheritance/editor tests, browser QA, fresh tests/fmt/strictClippy/build and independent scoped review. Complete the actual AWS slice before claiming its matrix entry complete; OAuth1, Hawk, NTLM, ASAP, EdgeGrid and other full-goal modules remain required.

Checkpoint: finite SDK wire adapter, bounded/inactive source validation, native/parent/env privacy, bilingual editor and Postman header mappings implemented. Seven core AWS tests include published AWS vectors and independent aws4 1.13.2 S3 presign vector; server inheritance/history and format roundtrip fixtures pass. Source/signature generation adapters for other languages and live protocols remain explicit unsupported paths, not completed capability claims. Future AWS SigV4a/ambient credential providers are separate capabilities, not assumed by this V4 source contract.
