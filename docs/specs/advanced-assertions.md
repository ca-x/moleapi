# Structured response assertions

Complete required response-check capabilities with header equality, regex matching/capture equality with advanced lookaround/backreference support, JSONPath, XPath1.0 and JSON Schema alongside existing status/duration/contains/JSON Pointer checks. Reuse regex, jsonpath-rust, sxd-document/sxd-xpath and jsonschema; no custom query/schema parsers. Stored assertion kinds are additive strings, retaining existing fields and old data compatibility.

JSONPath target selects JSON matches; expected is JSON (single match compares its value, multiple matches compare an array; no match fails). XPath target evaluates against XML; strings/nodes compare literal expected text, numbers/booleans parse expected accordingly. Root-declared namespace prefixes are bound; default namespaces can use local-name(). Regex target is a pattern; empty expected checks presence, otherwise compare first capture/whole match. Header names are case-insensitive and any duplicate value can satisfy equality. Schema expected contains an inline JSON Schema, target optionally selects a JSON Pointer instance. External schema retrieval is disabled and schema patterns retain advanced regex features under backtracking and worker limits.

Hosted/native response checks run in a capped application worker with a2s absolute deadline, bounded IPC and kill/reap on failure. Core evaluator remains available for trusted library/tooling use. Invalid, oversized, truncated or unsupported inputs fail explicitly. Bound expression/schema/node/depth/result sizes and never fetch schema/file/URL resources. Failed worker checks cannot appear passed. Assertion execution and histories share the current request/auth/script/privacy pipeline.

UI uses existing mature components/editor to select kinds and edit paths/patterns/schema with accurate labels. Each check returns passed/actual/expected with bounded diagnostic detail. Single requests and collection flows use the same behavior. Tests cover actual network response checks, typed query/schema values, namespace XML, regex captures, denied external refs and worker timeout/error handling, with owner/history and editor compatibility. User direction remains implementation first; no formal review before all remaining functions.
