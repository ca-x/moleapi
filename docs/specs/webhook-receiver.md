# Webhook receiver, inspector and replay

Authority protocols-016 in FEATURE-MATRIX, active full-feature goal and mature modular Rust requirement. Outbound notifications remain a separate integration capability.

Deliver persistent workspace-owned receivers with durable secret URL, pause/delete/revision controls, configurable real HTTP response, bounded durable requests, owner-only inspection/filter/safe-full export and explicit editable replay. Hosted service exposes callbacks; independent offline native client explicitly starts local HTTP listener. Axum/Hyper/SeaORM/checked reqwest/base64 own HTTP/storage/encoding; no custom parser or vendor SaaS.

Reuse document table with separate webhook-inbox/webhook-capture kinds and owner/workspace links, across SQLite/PostgreSQL/MySQL. Inbox retains cryptographic UUID-based-or-stronger capability token, name/response/active/revision/timestamps. Token excluded from logs/errors/ordinary capture preview/default export and inaccessible to other owners. Immutable capture: id/time/method/path-query/header pairs/raw-body-base64/length/content-type/response status. Never execute/fetch capture content.

Bounds: 64 captures/inbox and8MiB decoded aggregate, explicit overflow count;4 receivers/owner,128 global;32 intake slots/4 replay; body1MiB and5s intake, headers32KiB/512 fields; response64KiB/32 headers/status200..599. Remove hop/framing headers. Force CSP sandbox/default-src none and nosniff on receiver replies, including HTML. Stable cursor/order.

Public callback route /hooks/{token} accepts external callbacks without account credentials, inactive/deleted/missing safe404. Owner-authenticated /api/webhooks endpoints manage receivers/captures/replay/export. Worker determines exact DTO early, reports to root and appends here. Hosted address uses returned receiver_path plus frontend origin, never trusts Host/forwarded headers. Native explicit listener default localhost port0 or selected0..65535; optional all-interface binding only through explicit config/action, return actual origin/port and clear LAN guidance. Creating/listing must not silently start listener. Bounded stop/cancel/drop, no Arc self-cycle.

Weak workspace gates serialize receiver creation/active/deletion and ingest commit. Read body outside gate, then gate/reload current receiver revision and existing workspace inside guarded transaction; paused/deleted late writes cannot land. Workspace deletion cleans capture descendants transactionally, no orphans. Revision conflicts explicit. Hosted active receivers survive logout/restart; management authentication remains revocable. Local listener explicitly restarted/stopped, durable configs/captures retained. No automatic replay/tunnel/publication/external messaging.

Default inspection/export screens sensitive header/query/JSON fields, copied private values/encodings and echoed capability token using existing bounded helpers. Opaque binary conservatively hidden if unscreenable; explicit private/include-secrets gives exact original bytes only to owner. Display raw size/redaction. HTML/SVG/URIs are text/Hex/Base64, never active content.

Replay explicitly selects capture/destination/edited method-headers-query-body/timeouts/TLS/redirect and visible include_credentials. Never trust captured Host/Origin/destination; private/hop headers excluded by default. Use checked/pinned HTTP engine, actual status/headers/body/errors, raw binary reqwest bytes, progress/cancel, ownership/late UI fences. Response extraction/scripts/notifications remain separate shared modules.

Split server models/storage/manager/receiver/API/replay; root localized React/Radix/editor/query feature page. Fresh scoped review after freeze. Real HTTP fixtures for methods/query/duplicate headers/nonUTF8/custom response/error status, slow/large intake/concurrency/retention, forged owner/pause/delete/late writes/cascade/restart, safe/full privacy, native explicit bridge/stop, network policy/cancel/edited replay. Full source/frontend/browser/embed gates; no local Docker or premature main/release.

## Locked early API

GET/POST /api/workspaces/{workspace_id}/webhooks: list/create name,response{status,headers:Pair[],body}. Receiver view: id,workspace_id,name,token,active,response,revision,created_at,updated_at,received,dropped,receiver_path. GET/PUT/DELETE /api/webhooks/{id}: owner read/update name,active,response,expected_revision/delete expected_revision. GET /api/webhooks/{id}/captures?after&search&include_secrets; GET /api/webhooks/{id}/captures/{capture_id}?include_secrets; POST /api/webhooks/{id}/export{include_secrets}; DELETE /api/webhooks/{id}/captures clears bounded retained captures. Capture stores id,inbox_id,workspace_id,cursor,received_at,method,query,headers{name,value_base64,value_text},body_base64,body_bytes,response_status. Public path fixed /hooks/{token}, never stores token in URI path. Native listener POST /api/webhooks/listener/start{host,port}, GET /api/webhooks/listener, POST /api/webhooks/listener/stop returns actual local origin/bind/active; hosted mode rejects listener control. Replay POST /api/webhooks/{id}/replay{capture_id,replay_id,destination,method,headers,query,body_base64,timeout_ms,verify_tls,follow_redirects,include_credentials}; POST /api/webhooks/replay/cancel{replay_id}. Replay does not infer destination from captured request. DTO extras reject unknown fields where appropriate.
