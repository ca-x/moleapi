# Native CLI and CI entrypoint

Add a modular Rust moleapi-cli workspace binary using mature Clap4, the shared API and existing Rust format/execution/export modules. Remote mode addresses an explicit service URL; offline mode uses the existing headless server router in-process with an explicit worker path and background scheduling/notification loops disabled. No listening port, duplicate request engine, hand-parsed collection grammar or silent third-party generator downloads. Worker dispatch runs before CLI parsing so scripts/assertions/generation use the same bounded child pipeline.

Commands: login using a password environment variable and explicit private token-file output; metadata-only workspace/collection/environment/scenario/dataset listing; file import/native/Postman/OpenAPI/HAR/cURL conversion via shared formats; owned workspace export; collection/scenario runs with environment, saved or temporary CSV/JSON data, iterations, collection request filtering by ID/unique name without rewriting scenario graphs, notification override and CI origin; saved report view/export using shared JSON/CSV/JUnit/HTML; request snippet catalog/generation via the shared routes. Local input can be imported into a temporary isolated workspace/database when no persistent database is supplied. Resource IDs win; otherwise names must match uniquely. No arbitrary rerouting path interpolation.

Clap owns help/subcommands/argument validation and a machine-readable command schema is generated from its command metadata. Root modes/auth flags are exclusive. Remote bearer values come from a named environment variable or explicit bounded token file, not a token argument/log. Reject base URL credentials/query/fragments and redirects; add path segments safely. Bound input/response sizes and overall timeouts. Default stdout contains counters/report ID/metadata rather than live bodies/variables. Explicit exports retain existing default privacy and bounded native file writes. No overwrite without explicit flag; atomic private files use mature tempfile/0600 semantics.

Exit codes:0 completed passing/nonempty run,1 assertion/workflow failure or empty execution,2 usage/transport/storage/export error,130 user interrupt after requesting owned cancellation. Ctrl-C covers pending/in-flight work with the same job ID and finite follow-up deadline; it must not merely abandon a remote active run. CLI exports use stored redacted reports. Local mode queues notifications durably only; delivery requires an enabled serving instance. Packaging/Actions matrix follows after functional completion as requested.

Necessary actual CLI process fixtures: offline file import and HTTP/script/extraction/runner parity, remote authenticated run/metadata/report export, failure/empty/cancel codes, exact source preservation, env/dataset/name ambiguity, stdout credential withholding, exclusive modes and no file overwrite/background execution. CI docs include GitHub/GitLab/Jenkins invocation examples. Newman complete compatibility/custom reporter/runtime embedding, performance, distributed runner enrollment, remaining matrix work and final unified review/main release remain unfinished.
