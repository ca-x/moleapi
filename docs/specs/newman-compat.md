# Optional upstream Newman compatibility

The full matrix includes original Postman2.1 CLI/runtime/custom reporter/SDK behavior beyond the bounded native pm subset. Provide an explicit compatibility entrypoint that uses official Newman6.2.3, its matching Collection SDK4.4.0, Runtime7.39.1 and Collection Transformer4.1.8. Pin versions and dependency integrity in a separate optional npm package/lockfile. Do not implement another collection grammar, script emulator, event bridge, reporter contract or conversion engine.

`moleapi-cli newman --node /absolute/node --entrypoint /absolute/newman/bin/newman.js -- <official arguments>` forwards OS arguments/stdin/stdout/stderr/environment/current working directory and exit status to the configured installed upstream executable. Reject native server/database/token flags in this mode; do not create a native database/router or deliver stored jobs. Unix process replacement preserves terminal signals and upstream report flush behavior; Windows uses a foreground inherited process. No shell command interpolation, runtime installation/download or hidden fallback. The optional Node environment belongs to the caller; native/server/desktop operation stays independent of Node.

Expose the original programmatic Newman, Collection SDK, Runtime and Transformer APIs from tools/newman/index.cjs. Arbitrary upstream options and custom reporter packages use their original installation and resolution rules, not a MoleAPI subset. Upstream report/privacy behavior is distinct from native redacted owned reports. Compatibility execution does not automatically import/synchronize a remote workspace; users can explicitly export supported Postman collections first.

Necessary real fixture: original v2.1 collection, environment, CSV iterations, pre/post pm scripts and assertions, JSON/JUnit output, installed custom reporter receiving official events, upstream failure exit status and embedding API invocation against real HTTP. Native Docker/installer integration and broad platform/protocol/runtime combinations remain part of the later overall work.
