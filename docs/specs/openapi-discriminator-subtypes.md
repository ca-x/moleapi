Reuse explicit aliases whenever present. Otherwise add a deterministic, readable component name with a source-URI digest suffix to the derived generation projection; protect authored names against collisions. Resolve mapping URIs and ordinary reference aliases with strict existing URI-fragment semantics, including3.1 static IDs/anchors after registry normalization. Bare names in an external OpenAPI document refer to its own components when present.

Original/privacy documents and literal examples/defaults/extensions remain untouched. Model emitters and graph/cycle handling stay in their existing mature engines. Rebase ordinary references to promoted models through their canonical entry components; preserve those root pointers during mature bundling so recursive/cross-resource models remain named components rather than nested first-use copies.
