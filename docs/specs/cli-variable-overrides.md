# Private CLI and CI run-variable inputs

Expose the existing runner's temporary variables and local project/collection/environment overrides through bounded native CLI inputs. `run --variables-file PATH` and `run --variables-env NAME` are exclusive; the latter names an OS/CI variable containing JSON, never puts private values in command arguments. JSON envelope: `temporary` maps names to strings; `project`, `collection` and `environment` map names to strings or null tombstones. Parse with Serde, reject unknown envelope fields, enforce input/core size/count rules and compile into existing Pair/VariableUpdate models. All supplied values are private and must stay out of stdout, stored history/reports and default exports; do not mutate canonical workspace/environment values. Keep existing scope precedence, typed dataset semantics, selected environment and script/extraction behavior.

Read and validate override inputs before importing a temporary workspace or submitting execution. Environment overrides require a selected/active stored profile; users can use temporary values when no profile exists. The CLI does not reinterpret a native overlay envelope as a Postman environment file; original Newman environment-file behavior remains in the explicitly installed compatibility runtime. Selected Dev/Production profiles remain separate and unchanged.

Extend CI presets with an optional `variables_secret` reference containing this JSON envelope. Bind it to MOLEAPI_RUN_VARIABLES in GitHub/GitLab/Jenkins and pass only `--variables-env=MOLEAPI_RUN_VARIABLES`. No credential values enter generated YAML/Groovy/argv. File-mode CI gains runtime private variables without embedding them in its exported collection. Preserve auth-token/run-variable secret separation, reject alias collisions and reuse existing identifier validation, serialization, quoting, report/privacy and execution engines. UI accepts only a secret reference; the normal desktop/web variables UI remains unchanged. Necessary real process fixtures cover all scopes/precedence/deletion, selected profiles, canonical immutability, report/history privacy, malformed/missing/oversized inputs before network/import and generated file-mode CI with secret injection. Broader full-matrix/release work remains active.
