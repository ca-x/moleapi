# Workspace documentation search coverage

Scope: owner-only search of the current workspace draft under `documentation-009`, specified in `docs/specs/workspace-document-search.md`. This is not a public documentation-site index.

The Documents page searches authored Markdown titles/private sources and saved request names, methods, URLs, descriptions, eligible text bodies, response example names/bodies and enabled query/header names. It excludes auth credentials and parameter values. Literal Unicode case-insensitive AND terms rank title matches first, preserve source order within a rank and return bounded plain-text excerpts. Queries over 128 characters return no results; the page renders at most 100 results with the true total and a refinement hint. The search is derived from the current unsaved draft in memory, never persisted or sent to an endpoint, and clears on account/workspace change. A document result selects its exact document and focuses its heading; a request result uses the existing current account/workspace/request guard before opening the request editor.

Local evidence: three pure search regressions cover Unicode/literal metacharacters, multi-field terms, title ranking/order, private source, disabled/credential omission, exact draft retention, 160-character excerpts, overlong queries and a 101-match budget. Two page regressions cover private-source navigation, request navigation, stale account refusal and account/workspace search reset. The full frontend suite passed 406 tests; TypeScript, production frontend build and 46-chunk static ESM cycle verification passed. The final embedded server/CLI build passed.

At 390 px, the embedded English hosted UI searched a saved private Markdown source, opened its document and focused the title, then searched a saved request and opened its existing editor. No search or result-click API request was captured. After switching to Chinese, both a matching result and the zero-result state displayed without page-wide overflow. Focused axe reported zero violations and one incomplete contrast analysis because theme pseudo-elements obscured the inferred background.
