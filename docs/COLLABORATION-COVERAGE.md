# Hosted workspace collaboration coverage

Status: integrated feature still in progress in `feat/workspace-collaboration`. This file records evidence for the current worktree, not a released or merged capability. Authority: `docs/specs/workspace-collaboration.md` and `docs/COLLABORATION-ROUTE-POLICY.md`.

## Implemented paths

| Capability | Current evidence | Boundary |
| --- | --- | --- |
| Invitations and members | Hosted session create/list/revoke/accept, owner/admin role changes and removal, single-use digest tokens, same-account retry, per-acceptance generation and indexed cursor-paginated membership; cross-instance acceptance/rejoining and deletion/recreation tests | No organization/group ACL or delivery integration |
| Shared workspace data | Explicit owner/workspace GET for viewer-safe projection and editor/admin CAS PUT; owner IDs remain distinct when workspaces share an ID | Full editing parity with every workbench resource is pending |
| Shared execution | Editor/admin collection run, canonical saved-request execution, finite HTTP draft execution, saved SSE/WebSocket/Data sessions, saved Mock example preview and scoped routed Mock matching use the owner workspace and audit the real actor. Member live sessions bind the creator, fence membership/revision/credential changes and deny owner-only URLs | Other protocol sessions, public Mock share and runner routes remain owner-only; outbound side effects already sent before revocation cannot be rolled back |
| Saved results | Editor/admin history, report summary/detail/step response and Mock call reads recheck membership before returning; saved redacted report export is actor-audited and membership-fenced | Viewer private-result access and member report mutations remain closed |
| Shared Markdown | Viewer reads the existing privacy projection and safely previews nonprivate source; editor/admin create/edit/move/privacy-mark/remove documents through canonical workspace CAS with shared validation and delete confirmation | Document publication, password unlock, appearance and owner publication controls remain closed to members |
| Shared variables | Viewer reads projected project, collection and environment rows with secret values hidden; editor/admin edit shared rows and create/rename/select/delete environments through canonical CAS | Member local overrides, owned variable-file routes and a distinct team variable scope remain outside this editor |
| Audit | Successful invitation, membership and shared workspace writes append within their transaction; collection run start records the actor; owner/admin session lists latest 100 | Other resource actions need actor attribution before member access opens |
| Hosted client | Owner/admin invitation/member controls, one-time URL fragment link, current-session acceptance, distinct owned/shared picker keys with owner and role, viewer read-only request/document view, collection/folder create and settings, request copy/move/delete and collection-subtree deletion, saved scenario editing/execution, dataset source/query/view management, HTTP, Mock traffic/inline and linked Schema/v2 script/matching/dataset-binding and Markdown CAS editing, new unsaved HTTP request and distinct draft/saved send, collection run, Mock preview/history/report/Mock call view, pending-save edit retention, unsaved-change guard and shared query cleanup on workspace/account exit | OAuth token vault and document publication management stay owner-only; dedicated non-HTTP and advanced Mock/resource editors, remaining account switch/cache stress tests, native hosted sync and package validation remain open |
