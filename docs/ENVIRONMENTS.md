# 环境与变量

在「环境」页面创建开发、测试、预发布、生产等命名环境。各环境可以使用相同的变量名，例如 `base_url`、`token`，并设置不同的值。在工作台顶部的「当前环境」选择器切换环境，使用 `{{base_url}}`、`{{token}}` 引用当前环境的变量；禁用的变量不参与解析。

变量优先级从高到低为：临时变量、测试数据变量、环境变量、集合变量、项目变量。同一作用域中，本地值覆盖共享值，显式空字符串也是有效的覆盖值。

响应脚本支持读取响应 JSON 并更新本次执行所选环境：

```js
const body = pm.response.json();
pm.environment.set("token", body.access_token);
```

`pm.environment.get("token")` 读取环境变量，`pm.environment.unset("token")` 移除本地覆盖。脚本更新应用于本次执行所选环境的本地值；异步执行期间切换工作区、请求、账户或环境，过期结果不会写入新环境。不同环境的本地值分别保存。

浏览器的本地值按账户、工作区与作用域隔离；独立桌面客户端在本地数据库中保存本地值。默认同步和共享导出不包含本地值。共享值可以随工作区保存、同步；密钥标记会隐藏输入，默认导出排除密钥值，但不代表数据库加密。

目前响应提取使用响应脚本。可视化 JSONPath/正则等提取规则及实时消息提取界面尚未完成，不能据此宣称与 Apifox/Postman 完全对齐。
