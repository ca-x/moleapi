# Mock fault rate coverage

Scope: the opt-in failure-injection part of `mock-013`, specified in [mock-fault-rate.md](specs/mock-fault-rate.md). This builds on saved response examples, routed/public Mock, bounded delay and private call logs. It does not implement Postman's full Simulator or make the complete Mock module claim.

Saved examples default to `fault_rate_percent=0` and `fault_status=503`. A selected example with a nonzero rate draws independently per request. A hit returns the configured 500–599 status, a fixed text body and no authored response headers. The fault bypasses schema and script construction, then applies the existing bounded delay and revision check. Logs record actual status and the `simulated_failure` outcome without request or response data. External Postman/OpenAPI/HAR exports reject nondefault settings; both native backup modes retain them.

Local evidence in this branch: old JSON defaults, invalid percentages/statuses and backup/export tests passed. A real local router returned the unchanged 201 example at zero rate; at 100 percent, direct and routed calls returned configured 502 with only the fixed body, no private authored header, delayed at least 25 ms and logged the distinct outcome. An authored script that would throw is bypassed on the injected path. A hosted public share returned 503 without its private saved body and stopped working after revocation. A local native public listener returned 504 over a real socket. The focused editor and log suites passed 16 cases; the full frontend suite passed 378 cases with a clean TypeScript check. The full core/formats/server Rust suite passed after the new worktree's pinned OpenAPI Generator JAR was prepared and SHA256-verified. Strict scoped Clippy, rustfmt, diff checks and frontend production then embedded server builds passed. At 390px, a real browser saved 100%/502 in English, reloaded it, previewed and called the routed Mock for fixed 502 bytes, then switched to Chinese and saw localized controls/log outcome with no document overflow. axe reported zero verified violations and one incomplete background/contrast analysis. The freshly built embedded binary was also opened in the browser and returned the same saved controls and 502 preview. Fixed-head CI and installed package smoke remain open.

An intermediate rate is probabilistic, not a cluster-wide quota or fixed distribution. No connection reset, bandwidth shaping, dependency orchestration or per-minute limit is implemented. The older delay and static error-response features remain separate. Installed packages and the full 395-item goal remain open.
