# Published document search coverage

Scope: the anonymous public-site part of `documentation-009` described in [published-document-search.md](specs/published-document-search.md). Private workspace search is documented separately in `WORKSPACE-DOCUMENT-SEARCH-COVERAGE.md`; this profile never reads that private search source.

The public page searches only the already fetched immutable Markdown snapshot. A literal, bounded, locale-independent Unicode case-folded AND query matches published titles, folder labels and exact Markdown source; results preserve publication order. Unicode 16 full-fold exceptions are shipped in a small static table, and the current snapshot is folded once in memory. Empty query restores every published document. A nonempty no-match query shows an explicit status and leaves the selected article in place. Selection is a keyboard-operable button, does not change the public URL and does not request another API resource. Query/result text is not persisted or sent to a server. The anonymous page has an English/Chinese language switch and retains its site title when the locale changes.

Local evidence: focused pure and page tests cover Unicode normalization, literal metacharacters, AND terms, title/folder/source matching, stable order, empty/no-match state, anonymous one-fetch behavior and language switching. Independent review exposed `Straße`/`STRASSE` and browser-locale I/i mismatches; deterministic Unicode folding now covers those and Greek sigma, and focused re-review found no remaining Important issue. The final frontend suite passed 418 tests across 112 files; TypeScript, the production 46-chunk cycle verifier and refreshed embedded server build passed. In a real anonymous 390 px browser, a three-document snapshot filtered to `Operations guide`, Enter opened its article, no-match retained it, and switching Chinese/English changed the labels without changing the site title. A final rebuilt-browser recheck filtered uppercase `OPERATIONS` to the same result. The page fetched its public snapshot once during each search flow, kept document width at 390 px, and did not display the private sentinel. axe found zero violations and zero incomplete checks. The parent's root-folder save fix was also rechecked in the hosted owner browser: a new root document saved cleanly without a reload, then all three nonprivate documents were published in one snapshot.
