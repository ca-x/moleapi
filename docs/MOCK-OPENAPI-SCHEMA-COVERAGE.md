Scope: `docs/specs/mock-openapi-schema-link.md`, stacked on `feat/mock-schema-response`. A saved HTTP example may explicitly select a JSON response Schema from its own workspace's saved OpenAPI 3.0/3.1 JSON or YAML source. The link stores the specification ID and exact response-schema pointer; old static and inline-schema examples remain additive and unchanged.

The core parses one linked specification per workspace validation pass, checks method/status/media against the saved request/example, and resolves local response and component schema references. External/cyclic references, unsupported constructs and invalid/oversized pointers reject. The first linked profile supports the existing deterministic generator plus common string formats (`uuid`, `email`, `date`, `date-time`, `uri`) and OpenAPI nullable single-type forms.
